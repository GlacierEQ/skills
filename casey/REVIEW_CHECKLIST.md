# v0.1.0 Review Checklist

- [ ] One canonical repository; no new overlapping skills repository created
- [ ] Public and private overlays are separated
- [ ] Connector trust is distinct from factual status

- [ ] No private case facts or evidence locations appear in public files
- [ ] Allegations cannot be promoted to established facts
- [ ] Actor theories require source and element mapping

- [ ] Case and procedural-track isolation is preserved

## Skill Quality

- [ ] Every skill has bounded scope
- [ ] Inputs and outputs are clear
- [ ] Failure modes and prohibitions are explicit
- [ ] Exit criteria are testable
- [ ] Registry entries match paths and versions
